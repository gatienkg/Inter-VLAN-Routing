# Inter-VLAN-Routing
A Cisco Packet Tracer – Inter-VLAN Routing lab demonstrating VLAN segmentation, trunk configuration, router sub-interfaces, and communication between different VLANs using a Cisco router and Catalyst 2950-24 switch.

Cisco Packet Tracer – Inter-VLAN Routing

Project Overview

This project demonstrates the configuration and implementation of Inter-VLAN Routing using Cisco Packet Tracer.

The lab uses a Cisco router and a Catalyst 2950-24 Layer 2 switch to establish communication between devices located in separate Virtual Local Area Networks (VLANs).

The implementation demonstrates how VLAN segmentation separates network devices into different logical networks while allowing controlled communication between VLANs through a router.

Network Topology

The network consists of:

Router1: Provides inter-VLAN routing.
Switch0: Cisco Catalyst 2950-24 Layer 2 switch.
PC0: End-user workstation assigned to a VLAN.
PC1: End-user workstation assigned to another VLAN.
Project Objectives

Create and configure multiple VLANs.
Assign switch ports to their respective VLANs.
Configure trunking between the switch and router.
Implement router sub-interfaces for inter-VLAN communication.
Configure IP addressing and default gateways.
Enable communication between devices in different VLANs.
Verify network connectivity using ICMP ping tests.
